# Star Citizen Lore Codex — DM Knowledge Base

This folder holds the lore the companion DM uses to build stories, quests and campaign arcs
that we can actually play inside the Star Citizen Persistent Universe (PU).

**In-universe "now":** the year **2956** (the in-game calendar is real date + 930 years, so
October 2026 = October 2956). Live game version at time of writing: **Alpha 4.10.x** (4.10.2 rolling out in October 2026).

## Confidence notes

- **Older history (before 2950)** comes from long-standing official lore (Galactapedia, Comm-Link
  "Galactic Guide" and "Portfolio" articles). It's stable, but a few exact dates and names are marked `(?)`
  where sources disagree or couldn't be checked.
- **Live events (2023–2026)** were researched by web search in October 2026. The wiki
  (starcitizen.tools) couldn't be fetched directly, so details come from search summaries of
  the wiki, RSI, and game-news sites. Outcomes are stated where they were confirmed.
- CIG retcons lore now and then. When the game and this codex disagree, the game wins. Update
  this file and log the change.

## How the DM should use this

1. **Ground every quest in something that's actually in the game.** Places, mission types and
   enemies must exist in the current patch so the players can really do them (see the
   "Playable now" tags in `03-locations.md`).
2. **Use the lore for motive. Use the game for the action.** Example: "Find out what happened at Onyx
   Facility X" really means "fly to one of the abandoned ASD sites on a Stanton moon, clear it
   with FPS combat, and loot the data."
3. **Thread the canon.** Tie the group's own story to the official open threads in
   `05-dm-hooks.md` so it feels like part of the universe and not a side story.
